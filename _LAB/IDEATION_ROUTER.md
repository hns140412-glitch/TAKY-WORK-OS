# IDEATION ROUTER

Status: ACTIVE / EXPERIMENT ROUTER

Purpose: keep possibility search productive without promoting every idea into TAKY or a project contract.

Default route:
`IDEA → _LAB → QUICK VALUE TEST → EXPERIMENT / HOLD / REJECT / PROMOTE`

Minimum fields:
- idea
- source/context
- intended user value
- novelty: LOW / MEDIUM / HIGH / UNKNOWN
- usefulness: LOW / MEDIUM / HIGH / UNKNOWN
- expected cost/effort
- evidence state: IDEA / ANALOGY / EXTERNAL_REFERENCE / TESTED / OBSERVED
- dependency
- reversible test
- next action
- disposition: EXPERIMENT / HOLD / REJECT / PROMOTE

Rules:
- an interesting idea is not a project decision;
- a popular external pattern is not proof of fit;
- prefer a small reversible experiment when expected learning/value is high;
- do not require perfect evidence before a low-risk experiment;
- promotion requires an owner and observed/project-relevant value;
- rejected ideas remain searchable when the rejection reason may matter later.

Productive bias:
`CHEAP REVERSIBLE TEST + MATERIAL UPSIDE → TEST`
`NO OWNER / NO VALUE / HIGH COST → HOLD OR REJECT`

This router owns idea handling only. It does not override project authority.
