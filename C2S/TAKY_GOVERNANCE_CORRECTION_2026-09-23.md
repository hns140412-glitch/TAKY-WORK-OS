# TAKY GOVERNANCE CORRECTION — PRODUCTION AUTHORITY / USER EXPOSURE

Date: 2026-09-23
Status: ACTIVE CANDIDATE FOR CENTRAL PROPAGATION

## Governing principles

Think Again, Keep Your Key.
Think Again, You’re The Key.
HUMAN IS THE KEY != HUMAN IS THE DEBUGGER.
USER != DEBUGGER.

## Correction 1 — Governance must own execution permission

A rule that can be bypassed without blocking a production result is advisory, not governance.

ENGINE_AVAILABLE + BYPASS_USED = GOVERNANCE_FAILURE.

For artifact-producing domains, governance must define:
- authorized production route;
- artifact classes;
- forbidden production operations;
- mandatory validation dependencies;
- user exposure permission.

## Correction 2 — L8 USER EXPOSURE GATE

Validation is not complete until it controls whether the result can be shown.

NO PASS -> NO SHOW.

A user-facing preview is a production exposure event. Calling an artifact “preview” does not exempt it from source/fact/semantic safety.

## Correction 3 — Human approval is not defect detection

HUMAN APPROVAL is reserved for:
- intent choice;
- design choice;
- presentation choice;
- irreversible or high-impact approval;
- recipe lock.

It is not valid approval work to discover:
- deleted source geometry;
- stale/wrong source selection;
- invented semantics;
- unsupported narrative;
- obvious composition/crop/rotation defects;
- absent promised reference effect.

## Correction 4 — Resume mode taxonomy

HANDOFF must state one of:
- RESUME — continue last valid architecture;
- RETROSPECTIVE — analyze prior work without producing project output;
- SURGERY / RE-ARCHITECTURE — may supersede or deprecate prior architecture.

HANDOFF != OBLIGATION TO PRESERVE A KNOWN-BAD STRUCTURE.

## Correction 5 — PASS dimensions remain separate

SOURCE_FIDELITY != PRESENTATION_QUALITY.
CLARITY_GAIN != REFERENCE_EFFECT.
CODE_PASS != PRODUCT_PASS.
ENGINE_PASS != VISUAL_PASS.
COMPONENT_PASS != INTEGRATED_RESULT_PASS.

## Correction 6 — Reference utilization requires compilation

Reference presence or citation is not utilization.

REFERENCE NAME
-> MINED DNA
-> DESIGN TOKEN
-> ENGINE PARAMETER
-> OUTPUT EFFECT
-> BEFORE/AFTER VALIDATION

If the trace breaks, REFERENCE_EFFECT = FAIL/UNKNOWN, never PASS.

## Correction 7 — Metadata is not content authority

DATE != CONTENT CHANGE.
Filename != content identity.
Timestamp ordering may trigger re-check but cannot prove semantic/content difference.

## Cross-domain propagation

This correction applies beyond Drawing Engine wherever:
- one-off code can bypass an existing engine;
- generated output can mutate authoritative state;
- internal validation does not own user exposure;
- handoff can preserve flawed architecture;
- reference mining is disconnected from execution parameters.

Promotion to central TAKY requires exact-head regression evidence and conflict review against current master governance.
